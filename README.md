# CV 3.0 — Kirill Karachev

Interactive personal CV and portfolio for a product analyst / technical product specialist.

The current direction follows an editorial, image-led portfolio structure: cinematic hero, oversized story typography, layered sticky case studies, pointer perspective, parallax media and a full-screen contact ending.

## Content already included

- Umschool Camp Mini App — 10,000+ users
- attribution across 15 acquisition channels
- 206 technical and analytical deliveries in six months
- SQL, Python / Pandas, Power BI, Baserow, REST APIs, Google Apps Script, Next.js, React and TypeScript
- Vienna location and public contact links
